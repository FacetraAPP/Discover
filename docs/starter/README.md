# Fictional monthly sales

This minimal workspace contains the sales chart and overview dashboard. Its
three-row CSV is fictional and distributed under Apache-2.0.

data/sales.csv has month (YYYY-MM) and revenue (thousands of currency units).
The chart's min_revenue parameter filters rows; the dashboard binds it to its
threshold parameter. No connections or credentials are required.

Import this workspace in Facetra, open Monthly revenue, or open Sales overview
and apply a minimum revenue value. The chart displays months in chronological order.
