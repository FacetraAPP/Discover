# Example workspace

This is an editable copy of the complete built-in Facetra example workspace,
exported from `SampleContent.builtInContent()`. Resource IDs and bundled data
paths use `example` instead of the app-reserved `builtin_example` prefix.

It includes 11 charts, 4 dashboards and all four bundled CSV files. Stock,
sales and OHLCV records are fictional. No personal health data or credentials
are included.

The HTTP example requires a local Key-Value connection with the alias
`http_example` and an `endpoint` field set to `https://api.ipify.org`.
Connection values stay on the device. Health charts require a supported iOS
device and Apple Health read permission; they do not contain mock records.

Every chart, dashboard and local-file reference stays within this workspace.
